# File Size Checker

A simple Python desktop application that allows users to select a file and view its file name, type, and size.

## Features

- Select a file using a file picker
- Display the file name
- Display the file type
- Display the file size in KB or MB
- Clear the displayed result
- Handles canceling the file picker without crashing

## Built With

- Python
- Tkinter
- OS module

## How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python app.py
```
